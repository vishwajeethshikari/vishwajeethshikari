I'm a Computer Science student at KL University interested in building practical software at the intersection of AI engineering and backend development.

I enjoy turning ideas into working applications: designing REST APIs, connecting services, modelling relational data, exploring LLM-powered workflows, and solving algorithmic problems in Java.
- 🧠 AI engineering: Exploring LLM applications, retrieval-augmented generation (RAG), and AI-agent workflows.
- ⚙️ Backend engineering: Building with Java, Spring Boot, Python, FastAPI, REST APIs, and PostgreSQL.
- 🧩 Problem solving: Practising Data Structures & Algorithms in Java; 290+ LeetCode problems solved.
- ☁️ Cloud & systems: Learning cloud infrastructure, database scaling, testing, and deployment practices.
- 🤝 Teamwork: Building projects through Git, GitHub branches, code reviews, and incremental delivery.
My goal is to build software that is useful, reliable, and easy to understand—not just code that works once.
